LIVE MISSING-DOCUMENT TEST
The user explicitly authorized one call to a specific consenting test recipient,
at most 60 seconds and with Dial credit use, asking about a fictional missing document.
claim-demo.mts is an opt-in CLI, not a web dispatch endpoint or integrated case purpose.
It reserves a private attempt artifact outside the repository before one outbound POST.
The same path cannot redial. An unknown dispatch must be reconciled, never retried
with a fresh path. --read only retrieves the accepted call and stores transcript
privately; it does not dial. Console output omits recipient and transcript.

After separate authorization for a FUTURE call, prepare a new private path and run:
  DIAL_TEST_TO='<consenting E.164 recipient>' \
  DIAL_TEST_CONSENT_TO='<same recipient>' \
  DIAL_CLAIM_DEMO_ATTEMPT_FILE='<absolute private attempt file outside repo>' \
  node --env-file="$HOME/.config/speedhacks/dial.env" \
    src/integrations/dial/claim-demo.mts --live --confirm-credits

Read that attempt without placing another call:
  DIAL_CLAIM_DEMO_ATTEMPT_FILE='<same private attempt file>' \
  node --env-file="$HOME/.config/speedhacks/dial.env" \
    src/integrations/dial/claim-demo.mts --read
